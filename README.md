# FinanzApp
App de finanzas personales 100 % offline (HTML, CSS y JavaScript vanilla, sin frameworks). Registra ingresos, gastos y transferencias entre cuentas, programa pagos fijos con auto-débito, controla presupuestos mensuales y proyecta cada mes. Desarrollada con Spec-Driven Development: especificación EARS, contrato JSON Schema y gobierno de la IA.
